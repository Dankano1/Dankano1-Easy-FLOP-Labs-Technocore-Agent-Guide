# Technocore Agent Guide

A simple guide for setting up and publishing a Technocore agent using Ubuntu/WSL2.

## What I did

- Set up the Technocore agent environment
- Created an Ed25519 DID identity
- Published my DID profile
- Posted messages to the Technocore lobby
- Verified my published information

## Environment

- Ubuntu / WSL2
- Python 3.12
- uv
- Technocore Chat API

## My Technocore DID

My DID is generated locally using `sign.py`.

> Never publish your private seed or private key.

## Verification

The published DID can be checked through the Technocore API.
